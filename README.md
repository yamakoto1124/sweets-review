

# スイーツのレビュー

## サイト概要
### サイトテーマ
おすすめのスイーツを投稿したり、食感や甘みの好み・閲覧ランキングから自分にぴったりのスイーツを見つけられるレビューサイト

### テーマを選んだ理由
もともとスイーツが好きでレビューサイトやSNSをよく見ているのですが、写真映えする見た目と実際に食べたときの味や食感のギャップに頭を悩ませることが多くありました。
食感や甘みの強弱が直感的にカテゴリー分け・可視化されていれば、好みに合わせた理想のスイーツに出会えると考えました。
「ふわふわ」「もちもち」「サクサク」などの食感分類や甘さの指標を細かく整理し、食べたときのイメージの乖離が少ないサイトを作りたいと思い、このテーマに決めました。

### ターゲットユーザ
- 食感や甘みの好みにこだわりがあるスイーツ好きの方
- 「写真映え」だけでなく、味や食感の実際のレビューを重視して商品を選びたい人
- 自分のお気に入りのスイーツを詳細なレビュー（食感・甘み）とともに発信したい人

### 主な利用シーン
- カフェ巡りやテイクアウトの手土産選びで、失敗したくないとき
- 「今日は濃厚で硬めのプリンが食べたい」など、特定の食感・味わいからスイーツを探したいとき
- 実際に食べたスイーツの感想（食感・甘さ・満足度）を記録・共有したいとき
